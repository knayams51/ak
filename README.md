# Arun Kumar — Journalistic Archive & Author Website

Official digital archive and journalistic publication portal for **Arun Kumar**, Senior Assistant Editor / Associate Editor at *Hindustan Times* (Patna Bureau).

## Overview
This repository contains:
1. **`crawler/`**: Resilient stealth crawler engine with SQLite WAL request queue and author disambiguation engine for Hindustan Times author archives.
2. **`pipeline/`**: Normalization and packaging pipeline adhering to the *Non-Negotiable Body Rule* (zero paraphrasing), generating standardized `feed_run_*` packages.
3. **`site/`**: High-performance Astro Static Site Generator (SSG) with provenance bars, instant client-side full-text search, multi-tier Bihar beat taxonomy, and social media integration.
4. **`reports/`**: Automated QA verification reports, crawl summaries, and provenance audits.
